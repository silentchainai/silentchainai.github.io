SILENTCHAIN Changelog

Release notes for the SILENTCHAIN AI pentesting extensions for Burp Suite Professional. Highlights only - see each edition for full details.

Professional v2.0.41 Community v1.3.1

◆ SILENTCHAIN Professional

Java / Montoya extension for Burp Suite Professional - active verification, WAF fingerprinting, and 10 AI providers.

v2.0.412026-08-18
Fixed a passive-scan false-positive flood of "missing Content-Security-Policy" findings: CSP checks now run only on successful responses, skip the extension's own probe traffic, and are deduplicated per host.
v2.0.402026-08-17
Added request-header fuzzing to Phase 2 active verification (SSRF and proxy headers), improved out-of-band and server-side template injection (SSTI) verification accuracy, and overhauled the local Ollama provider for more reliable structured output.
v2.0.392026-08-16
Added API-focused active checks to Phase 2: GraphQL introspection, insecure deserialization, JWT alg:none and SAML signature stripping, mass assignment, and OAuth redirect_uri tampering.
v2.0.382026-07-26
Streamlined the Advanced settings panel.
v2.0.362026-07-20
Redesigned the HTML advisory report to match the SILENTCHAIN theme, with print and accessibility fixes.
v2.0.322026-07-14
Renamed to "SILENTCHAIN Professional" throughout the Burp UI, banner, settings, and report footers.
v2.0.312026-07-13
Added in-app updates: a license-gated download and guided install flow from inside Burp.
v2.0.302026-07-13
Improved local Ollama reliability on small models: structured JSON output, larger context window, and faster reasoning-model responses.
v2.0.292026-07-08
Fixed Phase 1 analysis timeouts so every AI provider honors the configured request timeout.
v2.0.282026-07-06
Added licensing and a first-run EULA, and hardened Phase 2 injection handling and HTML report output.
v2.0.142026-06-14
Faster Phase 2 active verification with concurrent payload sends (configurable concurrency).
v2.0.62026-06-13
Added HTML advisory report export.
v2.0.42026-06-13
Phase 2 active verification engine with out-of-band (OOB) callback testing.
v2.0.32026-06-13
Added 200+ curated payloads and WAF detection and fingerprinting for 24 WAF types.
v2.0.22026-06-13
Reached 10 AI providers, adding GPT-5.5, Claude Code, OpenRouter, and Z.ai.
v2.0.02026-06-13
SILENTCHAIN Professional v2: the Java / Montoya rewrite of the extension.

◆ SILENTCHAIN Community

Free, open-source Burp Suite Professional extension - AI-powered OWASP Top 10 detection.

v1.3.12026-07-13
Fixed local Ollama returning zero findings on small models (structured JSON output, context and repetition tuning, truncated-response recovery).
v1.3.02026-06-27
Rewritten as a native Java / Montoya extension. Burp AI is now the default provider, passive analysis is opt-in, and findings are emitted as native Burp issues.
v1.2.02026-03-29
Added the Azure OpenAI / Foundry provider, a persistent finding cache, CSV export, a start/stop scanning toggle, a runtime status panel, and a fixed thread pool for stable concurrency.
v1.1.42026-03-09
Detection and stability improvements.
Both editions are Burp Suite extensions and require Burp Suite Professional (not included). For full technical detail, see the documentation. Product pages: SILENTCHAIN Professional and SILENTCHAIN Community.
