Installation Guide

Everything you need to load SILENTCHAIN Professional into Burp Suite Professional, activate your license, and configure an AI provider.

Overview Requirements Installation Quick Start Settings

Before you start

Before installing SILENTCHAIN Professional, confirm that your environment meets the current Requirements for Burp Suite, supported platforms, licensing, and AI providers.

Once you've confirmed the requirements, follow the steps below to install the extension, activate your license, and configure your preferred AI provider.

Step 1 - Download the extension

SILENTCHAIN Professional is a commercial product. After you purchase a SILENTCHAIN Professional license, your license key and download link for the latest silentchain-pro-v2-X.Y.Z.jar are delivered by email. Save the JAR somewhere you can find it from Burp.

Don't have a Professional license yet? Purchase SILENTCHAIN Professional →

Step 2 - Load in Burp Suite

  1. Open Burp Suite Professional.
  2. Go to Extensions → Installed → Add.
  3. Set Extension type to Java.
  4. Under Extension file, click Select file... and choose the downloaded silentchain-pro-v2-X.Y.Z.jar.
  5. Click Next, then Close.

A new SILENTCHAIN Professional tab appears in Burp. Check the extension's Output / Errors tabs to confirm it loaded cleanly.

Step 3 - Activate your license

  1. Open the SILENTCHAIN Professional tab and click License.
  2. Paste your key (SCPRO-XXXX-XXXX-XXXX-XXXX) and click Activate.

A Professional license can be activated on one machine at a time and can be transferred to another machine when needed. License status is periodically validated, with a bounded offline grace period if the licensing service cannot be reached.

Until a valid license is activated, Professional analysis and verification features remain disabled.

Step 4 - Choose an AI provider

Open Settings in the SILENTCHAIN Professional tab and choose one provider.

Burp AI (default, zero-config)

If you have Burp Suite Professional with an active Burp AI entitlement and available credits, the default Burp AI provider works with no extra setup. Analysis is sent through PortSwigger's AI service and consumes your Burp AI credits. Skip ahead to Step 5.

Ollama - Local AI

Runs the AI model on your own hardware with no third-party AI API calls.

Ollama provides local AI models that run on your own hardware. Install Ollama for your operating system, download a compatible model, and make sure the Ollama service is running.

Install Ollama → · Ollama documentation

Then in SILENTCHAIN Professional Settings:

  1. Select Ollama as the AI provider.
  2. Enter your Ollama API URL (typically http://localhost:11434).
  3. Select a model you have installed.
  4. Click Test Connection.
  5. Click Save.
AI Provider: Ollama
API URL:     http://localhost:11434
Model:       llama3:latest

For Ollama installation, supported operating systems, GPU requirements, and model-specific requirements, refer to the current Ollama documentation.

When configured with Ollama, AI analysis can remain entirely on your hardware.

Cloud providers (OpenAI, GPT-5.5, Claude, Claude Code, Gemini, OpenRouter, Z.ai, Azure AI Foundry)

SILENTCHAIN needs an API key (and, for some providers, an endpoint URL or deployment name) from the provider you choose. Account creation, billing, model availability, and key management are handled by the provider - see the provider's current documentation for those steps.

  1. Create an API key in the provider's console.
  2. In Settings, select the provider and paste the API key.
  3. Pick a model, click Test Connection, then Save.

Provider-specific endpoints, authentication headers, and settings are listed in the settings reference.

SILENTCHAIN applies best-effort PII and secret redaction before content is sent to a cloud AI provider. For the strongest data-locality configuration, use a local provider such as Ollama.

Step 5 - Enable AI analysis

In Settings, enable AI analysis. Passive analysis is off by default. You can also analyze individual requests manually using Analyze with SILENTCHAIN AI from the Burp context menu.

Phase 2 active verification is controlled separately and is also off by default.

Step 6 - Verify the install

  • The SILENTCHAIN Professional tab is present and the License shows as active.
  • The extension's Errors tab is clean.
  • Test Connection succeeds for your chosen provider.
  • Right-clicking a request in Proxy/Repeater/Target shows Analyze with SILENTCHAIN AI.

Troubleshooting

SymptomFix
No SILENTCHAIN Professional tab after loadingConfirm extension type was Java and check the Errors tab; make sure you are on Burp Suite Professional 2025.2+
License won't activateVerify the key and confirm that outbound HTTPS access to the licensing service is available. If the licensing service is temporarily unreachable, the license's offline grace period may allow continued use
Burp AI errors or no outputConfirm an active Burp AI entitlement with available credits, or switch to Ollama / another provider
Ollama "connection refused"Ensure ollama is running and reachable at http://localhost:11434 (ollama list to confirm)
Analysis features do nothingCheck that the license is active and Enable AI analysis is toggled on

Authorized use only. Only analyze and test targets you have explicit written permission to assess. Phase 2 active verification sends crafted payloads to the target you select.
