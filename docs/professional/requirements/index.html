SILENTCHAIN Professional runs as an extension inside Burp Suite Professional. Burp Suite is a separate product from PortSwigger, is not included with SILENTCHAIN, and you provide your own Burp Suite Professional license.

Supported platforms

The extension is distributed as a single self-contained Java archive (silentchain-pro-v2-X.Y.Z.jar) with no native components and no separate installer. If Burp Suite Professional runs on your machine, SILENTCHAIN Professional runs there too.

PlatformStatusNotes

Burp Suite CommunityNot supportedSILENTCHAIN requires Burp Suite Professional

The Java runtime bundled with current Burp Suite Professional releases satisfies the Java 21 requirement. If you launch Burp from a standalone JAR against your own JVM, that JVM must be Java 21 or later.

Hardware and resources

SILENTCHAIN Professional itself is lightweight: the extension JAR is well under 1 MB and adds no database or background service. In practice your requirements are driven by two things - Burp Suite Professional itself, and whether you choose to run a local AI model.

ScenarioWhat drives the requirement
Cloud or Burp AI providerBurp Suite Professional's own system requirements apply. The extension adds negligible CPU, memory, and disk overhead.
Local AI provider (Ollama)The machine hosting Ollama needs enough RAM, disk, and ideally GPU capacity for the model you choose. Requirements vary widely by model - see the Ollama documentation for model-specific guidance.
Phase 2 active verificationVerification sends additional HTTP requests to the target. Concurrency and payload count are tunable in Settings.

Ollama does not have to run on the same machine as Burp. Pointing SILENTCHAIN at an Ollama instance elsewhere on your own network keeps analysis inside your perimeter without requiring a workstation-class GPU.

Network & offline operation

SILENTCHAIN Professional's network requirements depend on the AI provider and features you use.

Local AI: When using Ollama with a local model, AI analysis can run entirely on your own hardware. Requests, responses, credentials, and findings are not sent to a third-party AI provider.

Cloud AI: Cloud providers such as OpenAI, Claude, Gemini, OpenRouter, Z.ai, and Azure AI Foundry require network access and may have their own API or usage charges.

Burp AI: The Burp AI provider uses PortSwigger's AI service and requires an active Burp AI entitlement with available credits.

Licensing: Professional license activation and periodic license validation may require connectivity to the SILENTCHAIN licensing service. A bounded offline grace period allows continued use when the licensing service cannot be reached.

Out-of-band testing: OOB verification may require network connectivity between the target and the configured callback service.

Air-gapped deployments: Professional can be configured for local AI operation without sending analysis data to third-party AI services. Fully disconnected operation also depends on your licensing, update, and testing configuration.

License activation

SILENTCHAIN Professional requires a valid license key in the form SCPRO-XXXX-XXXX-XXXX-XXXX. Open the License dialog from the SILENTCHAIN Professional tab, paste your key, and click Activate.

A Professional license can be activated on one machine at a time and transferred to another machine when needed. License status is periodically validated, with a bounded offline grace period when the licensing server cannot be reached.

Transfers are self-service: click Deactivate in the License dialog on the machine currently holding the activation to release it, then activate on the new machine. If a machine is lost or can no longer run Burp, contact us so we can help release the activation.

Without a valid license, Professional analysis and verification features are disabled.

What SILENTCHAIN does not require

  • No separate server or database. Everything runs inside Burp Suite Professional.
  • No AI subscription from us. You bring your own provider - Burp AI credits, a cloud API key, or a self-hosted model.
  • No Sn1per installation. SILENTCHAIN is a standalone product and does not integrate with the Sn1per platform.
  • No replacement for Burp Suite. SILENTCHAIN extends the Burp workflow you already use; it does not include or replace Burp Suite Professional.
